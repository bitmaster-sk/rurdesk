The headline act

Hand a ticket to an agent. Get back a pull request.

Assign an issue to a bot backed by a Goose gateway. The agent moves through staged phases with a human approval gate between each one. Nothing merges without you.

  • Each run works in an isolated git worktree, pushes a branch, opens a PR/MR
  • Approval gates between stages — you stay in control
  • Crash recovery, heartbeats, and per-run stats: tokens, duration, tool calls
  • Run multiple agents in parallel on independent tickets
  • Run fully local via Ollama — no cloud, no keys — or bring your own (Anthropic, Gemini, Ollama Cloud)

AI in the backlog

Every ticket gets smarter before it gets built.

Project Kickstarter

Describe a project in a few sentences. The AI generates a staged backlog — titles, descriptions, hierarchy, and schedule relations — shown in a staging view. One click accepts the whole plan.

  • Sentence → structured backlog in one step
  • Review everything before anything is saved
project kickstart

Quality Check

An inline quality score on every issue you create or edit, with concrete improvement suggestions — missing context, vague acceptance criteria. The AI suggests, you decide.

  • Catch weak tickets before they reach the backlog
  • Visible to every user from day one
issue quality

Issue Split

Click split on a big ticket, optionally steer how it should be broken down, and the AI proposes the right child tasks. Review and accept — nothing is created without your sign-off.

MCP server

The whole backlog is drivable from any MCP-capable tool — Claude Code, Cursor — via create_issue, list_issues, add_relation, and friends.
